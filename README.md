# LermLearn

LermLearn คือโปรแกรมช่วยวางแผนการเรียนสำหรับนักเรียน เชื่อมต่อ Google Classroom เพื่ออ่านงานและเอกสารที่ผู้ใช้มีสิทธิ์เข้าถึง แล้วใช้ AI ช่วยสรุปเนื้อหา สร้างข้อสอบ และสร้างแฟลชการ์ด โดยออกแบบให้ผู้ใช้ตรวจสอบแหล่งข้อมูลและเหตุผลของผลลัพธ์ได้

## สำหรับกรรมการผู้ทดสอบ

ให้ดาวน์โหลดเฉพาะไฟล์ `.exe` จาก GitHub Release/Tag ของรุ่นที่ส่งประกวด ไม่ต้องดาวน์โหลด source code และไม่ต้องเปิดโฟลเดอร์ `dist-logo-fix` บนเครื่องผู้พัฒนา

หลังติดตั้ง กรรมการต้องทำเพียง 2 อย่าง:

1. ใส่ AI API key ของตนเองในหน้าตั้งค่าครั้งแรก (แนะนำ Qwen)
2. กดเชื่อมต่อ Google Classroom แล้วเลือกบัญชี Google ของกรรมการ

ไม่ต้องกรอก Google OAuth Client ID, Client Secret, Redirect URI และไม่ต้องสร้าง OAuth Client ใหม่ ตัวติดตั้งใช้ OAuth Desktop Client ของแอปกับ PKCE และไม่ฝัง Client Secret ไว้ในตัวติดตั้ง

สิ่งที่ต้องมีคือ Windows 10/11 แบบ 64-bit, อินเทอร์เน็ตขณะเชื่อมต่อ Google และบัญชี Google ที่เข้าถึงข้อมูล Classroom/Calendar ที่ต้องการทดสอบได้

## ติดตั้งสำหรับผู้ใช้ทั่วไป

> **สำคัญ:** ผู้ใช้ทั่วไปไม่ต้องเข้าไปติดตั้งจากโฟลเดอร์ `dist` เพราะ `dist` เป็นโฟลเดอร์ผลลัพธ์สำหรับผู้พัฒนาเท่านั้น

1. ไปที่หน้า [GitHub Releases](https://github.com/Snowmagic-lab/LermLearnAi/releases)
2. เปิด Release/Tag ของรุ่นที่ต้องการ แล้วดาวน์โหลดไฟล์ `LermLearn Setup 0.1.0.exe` จากส่วน **Assets**
3. ดับเบิลคลิกไฟล์ติดตั้ง และเลือกโฟลเดอร์ที่ต้องการติดตั้ง
4. เปิด LermLearn จาก Desktop หรือ Start Menu
5. ในหน้าตั้งค่าครั้งแรก เลือกผู้ให้บริการ AI และใส่ **AI API key** ของตนเอง
6. กดบันทึก แล้วกด **เชื่อมต่อ Google Classroom** ในโปรแกรม
7. เลือกบัญชี Google ตรวจสอบสิทธิ์ แล้วกดยอมรับ

ผู้ใช้ทั่วไปไม่ต้องกรอก Google OAuth Client ID, Client Secret หรือเพิ่ม Test users เพราะ OAuth Client ID ของแอปถูกเตรียมไว้ในโปรแกรมแล้ว ผู้ใช้แต่ละคนยังต้องเลือกบัญชี Google และยอมรับสิทธิ์ของตนเอง

### ลิงก์สำหรับสร้าง API key

แนะนำให้ใช้ **Qwen** สำหรับสรุปเอกสาร สร้างข้อสอบ และแฟลชการ์ด

- [สร้าง Qwen API key (แนะนำ)](https://bailian.console.alibabacloud.com/?tab=api#/api-key)
- [สร้าง Gemini API key](https://aistudio.google.com/app/apikey)
- [สร้าง DeepSeek API key](https://platform.deepseek.com/api_keys)

คีย์จะถูกเก็บไว้เฉพาะในเครื่องของผู้ใช้ ห้ามส่งคีย์ให้ผู้อื่นและห้าม commit คีย์ลง GitHub

## สิ่งที่ต้องตรวจสอบหลังติดตั้ง

- Google Classroom API, Google Drive API และ Google Calendar API ของแอปต้องเปิดใช้งานอยู่
- บัญชี Google ต้องมีสิทธิ์เข้าถึงห้องเรียน งาน และไฟล์ที่ต้องการอ่าน
- ต้องอนุญาตสิทธิ์ Google Drive หากต้องการให้ระบบอ่านข้อความจากไฟล์แนบหรือสไลด์
- ต้องมีอินเทอร์เน็ตและ API key ที่ยังใช้งานได้ หากต้องการใช้ AI ออนไลน์
- บัญชีโรงเรียนอาจถูกนโยบายของผู้ดูแลระบบบล็อกการเชื่อมต่อ OAuth

### คำเตือนเรื่อง Google OAuth

แม้ไม่ต้องเพิ่ม Test users แล้ว Google อาจยังแสดงคำเตือน “แอปยังไม่ผ่านการยืนยัน” เพราะแอปขอสิทธิ์ Calendar หรือสิทธิ์ข้อมูลอื่น ผู้ใช้ควรอ่านและตรวจสอบรายการสิทธิ์ก่อนกดยอมรับ และบัญชีโรงเรียนอาจถูกนโยบายผู้ดูแลระบบบล็อกได้

### คำเตือนเรื่อง Google Calendar และความเป็นส่วนตัว

LermLearn สามารถอ่านตารางจาก Google Calendar เพื่อใช้ประกอบการวางแผนการเรียนและการทำงาน โดยคำนึงถึงเวลาว่าง เวลาพัก และเวลานอนของผู้ใช้

ในเวอร์ชันทดลอง ระบบยังไม่แก้ไขข้อมูลใน Google Calendar โดยตรง เพื่อจำกัดสิทธิ์การเข้าถึงข้อมูลส่วนตัวของผู้ใช้และเพิ่มความปลอดภัย ปฏิทินการทำงานของ LermLearn สามารถจัดและแก้ไขแผนได้ภายในแอป

## ฟังก์ชันหลักในรุ่นนี้

- ดึงรายวิชา งาน และกำหนดส่งจาก Google Classroom
- อ่านรายละเอียดคำสั่งงาน กำหนดส่ง คะแนน และไฟล์แนบที่บัญชีผู้ใช้เข้าถึงได้ก่อนวางแผน
- ประเมินเวลาและความยากจากข้อความที่อ่านได้ พร้อมแสดงเหตุผล หลักฐาน และแจ้งรายการที่อ่านไม่ได้
- แสดงงานที่ยังไม่เสร็จและงานที่ส่งแล้วตามช่วงเวลาที่เหมาะสม
- วางแผนการทำงานและการติวโดยคำนึงถึงกิจวัตร เวลาพัก และเวลานอน
- อ่านข้อความจาก PDF, PowerPoint, Word และไฟล์ข้อความที่ผู้ใช้เลือก
- สรุปเนื้อหาโดยยึดข้อมูลที่อ่านได้จากไฟล์
- สร้างข้อสอบแบบเลือกตอบพร้อมเฉลย เหตุผล และแหล่งอ้างอิง
- สร้างแฟลชการ์ดพร้อมคำตอบ เหตุผล และแหล่งอ้างอิง
- ดาวน์โหลดผลลัพธ์เป็น PDF
- มีโหมดออฟไลน์สำหรับทดสอบหน้าจอ Summary, Quiz และ Flashcard ด้วยข้อมูลตัวอย่าง

หากระบบอ่านไฟล์ไม่ได้หรือข้อมูลไม่เพียงพอ ระบบควรแจ้งข้อจำกัดตรง ๆ และไม่แต่งข้อมูลแทนเนื้อหาในเอกสาร

## การติดตั้งสำหรับนักพัฒนา (Dev)

ต้องมี Node.js 20 ขึ้นไป จากนั้นเปิด PowerShell ในโฟลเดอร์โปรเจกต์:

```powershell
npm install
```

การ build installer รุ่นนี้ไม่ต้องใส่ไฟล์ `google-oauth-client.json` และจะไม่ฝัง Client Secret ลงในตัวติดตั้ง ตัวโปรแกรมใช้ OAuth Desktop Client ID ที่เป็นข้อมูลสาธารณะร่วมกับ PKCE และ loopback redirect เพื่อให้ผู้ทดสอบติดตั้งแล้วล็อกอินได้โดยไม่ต้องกรอก Client ID หรือ Client Secret

หากนักพัฒนาต้องการใช้ OAuth ของโปรเจกต์อื่นในโหมด Dev สามารถคัดลอก `google-oauth-client.example.json` เป็น `google-oauth-client.json` แล้ววางไฟล์ไว้ที่โฟลเดอร์หลักได้ แต่ไฟล์นี้เป็นข้อมูลเฉพาะเครื่อง ห้าม commit ขึ้น GitHub และไม่ควรนำเข้า installer

### เปิดเป็น Desktop app ระหว่างพัฒนา

```powershell
npm run desktop
```

หรือใช้ไฟล์:

```text
run-studyflow-dev.bat
```

### เปิด server สำหรับทดสอบผ่าน browser

```powershell
npm run dev
```

จากนั้นเปิด `http://127.0.0.1:4173`

### สร้างไฟล์ติดตั้ง

```powershell
npm run dist
```

คำสั่งนี้จะสร้างไฟล์ติดตั้งไว้ในโฟลเดอร์ `dist-logo-fix` สำหรับผู้พัฒนาเท่านั้น จากนั้นให้นำไฟล์ `.exe` ไปแนบใน GitHub Release/Tag เพื่อให้ผู้ใช้ทั่วไปดาวน์โหลด โฟลเดอร์ `dist` ไม่ได้ใช้ในโปรเจกต์รุ่นนี้แล้ว ผู้ใช้ทั่วไปควรดาวน์โหลดไฟล์ `.exe` จาก GitHub Release/Tag

## การตั้งค่าในโหมด Dev

ไม่ควรใส่ API key ลงใน source code ให้สร้างไฟล์ `.env.local` จาก `.env.example` และเก็บไว้เฉพาะเครื่องนักพัฒนา ตัวอย่างค่าที่เกี่ยวข้อง:

```env
AI_PROVIDER=qwen
QWEN_API_KEY=ใส่คีย์ของคุณ
QWEN_MODEL=qwen3.7-plus
QWEN_BASE_URL=https://dashscope-intl.aliyuncs.com/compatible-mode/v1
```

ในโหมดติดตั้ง ผู้ใช้กรอกเฉพาะ AI API key ผ่านหน้าต่าง setup ส่วน OAuth Client ID แบบ Desktop ของแอปถูกเตรียมไว้ใน `server.mjs` และระบบจะไม่อ่าน Client ID, Client Secret หรือ Redirect URI จากไฟล์ตั้งค่าของผู้ใช้ เพื่อป้องกันค่าจากรุ่นเก่าทำให้ล็อกอินผิดพลาด การแลก token ใช้ PKCE และจะส่ง Client Secret เฉพาะเมื่อพบไฟล์ OAuth local สำหรับ Dev เท่านั้น

## การเก็บข้อมูลและความปลอดภัย

- `.env.local` และ `google-token.json` ไม่ควรอัปโหลดขึ้น GitHub
- API key ของผู้ใช้ถูกเก็บไว้ในเครื่องนั้นเท่านั้น
- OAuth token ถูกเก็บในโฟลเดอร์ข้อมูลของผู้ใช้ตามระบบปฏิบัติการ
- ข้อมูล Classroom และไฟล์ส่วนตัวต้องใช้เฉพาะเมื่อผู้ใช้อนุญาต
- โหมดครูและการวิเคราะห์ข้อมูลรวมเป็นแผนงานในอนาคต ยังไม่ใช่ฟังก์ชันพร้อมใช้งานในรุ่นนี้

## ฟังก์ชันที่คาดว่าจะมาในเวอร์ชันถัดไป

> ส่วนนี้เป็นแผนงานที่อยู่ระหว่างการออกแบบและทดสอบ ยังไม่ถือว่าเป็นฟังก์ชันที่พร้อมใช้งานในรุ่นปัจจุบัน

### โหมดครู (Teacher Mode)

มีแผนเพิ่มเครื่องมือสำหรับครูเพื่อช่วยวิเคราะห์ภาระงานและเตรียมการสอน โดย AI จะช่วยเสนอข้อมูลและเหตุผล แต่ครูยังเป็นผู้ตรวจสอบและอนุมัติทุกครั้ง

- ภาพรวมภาระงานของห้องและช่วงเวลาที่งานหนาแน่น
- ผู้ช่วยตรวจคำสั่งงาน แบ่งขั้นตอน และประเมินเวลาที่นักเรียนต้องใช้
- แจ้งเตือนเมื่อกำหนดส่งอาจชนกับงานจากวิชาอื่น
- ช่วยร่างสรุป ใบงาน คำถามทบทวน ข้อสอบ และแฟลชการ์ดจากเอกสารที่ครูเลือก
- ตรวจประกาศก่อนโพสต์ เพื่อหาข้อมูลที่ขาดหรือข้อความที่อาจทำให้เข้าใจผิด
- แสดงผลการส่งงานแบบภาพรวมโดยไม่จัดอันดับนักเรียน
- เสนอหัวข้อทบทวนเพิ่มเติมจากผลข้อสอบของนักเรียนจำนวนมาก

หลักการสำคัญคือใช้ข้อมูลเท่าที่จำเป็น แสดงเหตุผลและแหล่งข้อมูล ไม่จัดอันดับนักเรียนโดยอัตโนมัติ และไม่ให้ AI โพสต์งานหรือเปลี่ยนกำหนดส่งโดยไม่มีการอนุมัติจากครู
