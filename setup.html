LERMLEARN CONNECTION SETUP

เริ่มต้นใช้งาน LermLearn

กรอก API key ของผู้ให้บริการ AI เพียงหนึ่งคีย์ แล้วกดเชื่อมต่อ Google ด้วยอีเมลของคุณในแอป ผู้ใช้ทั่วไปไม่ต้องกรอก Google OAuth Client ID, Client Secret หรือเพิ่มอีเมลใน Test users

ขั้นตอนสั้น ๆ
  1. เลือกผู้ให้บริการ AI และสร้าง API key หนึ่งคีย์ — แนะนำ Qwen สำหรับการสรุป สร้างข้อสอบ และแฟลชการ์ด
  2. วาง API key ในช่องด้านล่างแล้วกดบันทึก
  3. เมื่อแอปเปิดขึ้น ให้กด “เชื่อมต่อ Google Classroom” และเลือกบัญชีของคุณ
  4. ตรวจสอบสิทธิ์ที่ขอ แล้วกดยอมรับ ระบบจะแสดงเฉพาะข้อมูลของบัญชีที่คุณอนุญาต
สร้าง Qwen API key (แนะนำ)คู่มือ QwenGemini API key (เสียง Athena)สร้าง DeepSeek API key
การเข้าถึง Google Calendar และข้อมูลส่วนตัว

LermLearn สามารถอ่านตารางจาก Google Calendar เพื่อใช้ประกอบการวางแผนการเรียนและการทำงาน โดยคำนึงถึงเวลาว่าง เวลาพัก และเวลานอนของผู้ใช้

ในเวอร์ชันทดลอง ระบบยังไม่แก้ไขข้อมูลใน Google Calendar โดยตรง เพื่อจำกัดสิทธิ์การเข้าถึงข้อมูลส่วนตัวของผู้ใช้และเพิ่มความปลอดภัย ปฏิทินการทำงานของ LermLearn สามารถจัดและแก้ไขแผนได้ภายในแอป

  • แอปจะอ่านเฉพาะข้อมูลที่คุณกดยอมรับ และใช้ข้อมูลเพื่อฟังก์ชันที่เกี่ยวข้องเท่านั้น
  • API key ถูกเก็บไว้ในเครื่องของคุณ ไม่ควรส่งต่อหรือเผยแพร่ในภาพหน้าจอหรือไฟล์ GitHub
  • Google อาจแสดงคำเตือนแอปยังไม่ผ่านการยืนยันสำหรับผู้ใช้ใหม่ ให้ตรวจชื่อแอปและสิทธิ์ก่อนกดยอมรับ
  • หากบัญชีโรงเรียนมีนโยบายบล็อกแอปภายนอก อาจต้องให้ผู้ดูแลระบบอนุญาต

OAuth Client ของ LermLearn ถูกเตรียมไว้ในตัวโปรแกรมแล้ว ผู้ใช้จึงไม่ต้องกรอก Client ID/Secret ในหน้านี้ หากคุณพัฒนาแอปเอง สามารถตั้งค่าแทนที่ผ่านไฟล์ environment ได้
