# LermLearn

LermLearn คือโปรแกรมช่วยวางแผนการเรียนสำหรับนักเรียน โดยเชื่อม Google Classroom เพื่ออ่านรายวิชา งาน และกำหนดส่ง แล้วใช้ AI ช่วยสรุปเนื้อหา สร้างข้อสอบ และสร้างแฟลชการ์ดจากไฟล์ที่ผู้ใช้เลือก

## ติดตั้งและเริ่มใช้งานสำหรับผู้ใช้ทั่วไป

### สิ่งที่ต้องมี

- Windows 10/11 64-bit
- บัญชี Google ที่มีสิทธิ์เข้าถึง Google Classroom ของตนเอง
- อินเทอร์เน็ตสำหรับล็อกอิน Google และเรียก AI
- API key ของผู้ให้บริการ AI หนึ่งราย แนะนำ Qwen สำหรับการทดลอง

### ติดตั้ง

1. ดาวน์โหลดไฟล์ `LermLearn Setup 0.1.0.exe` จากโฟลเดอร์ `dist` หรือจาก GitHub Release ของโปรเจกต์
2. เปิดตัวติดตั้ง เลือกโฟลเดอร์ แล้วกด Install
3. เปิด LermLearn จาก Desktop หรือ Start Menu
4. ในหน้าตั้งค่าครั้งแรก เลือกผู้ให้บริการ AI และวาง API key เพียงหนึ่งคีย์
5. กดบันทึกและเปิด LermLearn จากนั้นกด **เชื่อมต่อ Google Classroom**
6. เลือกบัญชี Google ของผู้ใช้ ตรวจสอบชื่อแอปและสิทธิ์ แล้วกดยอมรับ

ผู้ใช้ทั่วไป **ไม่ต้องกรอก Google OAuth Client ID, Client Secret และไม่ต้องเพิ่มอีเมลใน Test users** เพราะตัวติดตั้งใช้ OAuth Client ของแอปที่เตรียมไว้ให้แล้ว การล็อกอินแต่ละคนยังเป็นการอนุญาตข้อมูลของบัญชีตนเองแยกจากกัน

### เลือก API key

แนะนำให้ใช้ Qwen ก่อน เพราะเหมาะกับการทดลองสรุปเอกสารภาษาไทยและสร้างสื่อทบทวน

- [สร้าง Qwen API key — แนะนำ](https://modelstudio.console.alibabacloud.com/?tab=dashboard#/api-key)
- [คู่มือ Qwen API key](https://www.alibabacloud.com/help/en/model-studio/developer-reference/get-api-key)
- [สร้าง Gemini API key (ใช้กับเสียง Athena ในรุ่นที่รองรับ)](https://aistudio.google.com/app/apikey)
- [สร้าง DeepSeek API key](https://platform.deepseek.com/api_keys)

เลือกผู้ให้บริการให้ตรงกับคีย์ที่นำมาวาง หากใช้ Qwen ให้เลือก `Qwen (แนะนำ)` ในหน้าตั้งค่า

หมายเหตุ: Gemini API key ในลิงก์ด้านบนเป็นทางเลือกสำหรับส่วนเสียง Athena ของรุ่นที่รองรับ ไม่ใช่ตัวเลือก AI หลักในหน้าตั้งค่าเวอร์ชันนี้ หากต้องการสรุป/สร้างข้อสอบ/แฟลชการ์ด ให้ใช้ Qwen หรือ DeepSeek ตามตัวเลือกในโปรแกรม

## สิทธิ์ Google และความเป็นส่วนตัว

LermLearn สามารถอ่านตารางจาก Google Calendar เพื่อใช้ประกอบการวางแผนการเรียนและการทำงาน โดยคำนึงถึงเวลาว่าง เวลาพัก และเวลานอนของผู้ใช้

ในเวอร์ชันทดลอง ระบบยังไม่แก้ไขข้อมูลใน Google Calendar โดยตรง เพื่อจำกัดสิทธิ์การเข้าถึงข้อมูลส่วนตัวของผู้ใช้และเพิ่มความปลอดภัย ปฏิทินการทำงานของ LermLearn สามารถจัดและแก้ไขแผนได้ภายในแอป

เพิ่มเติม:

- แอปอ่านเฉพาะข้อมูลที่ผู้ใช้กดยอมรับ และใช้ข้อมูลตามฟังก์ชันที่เกี่ยวข้อง
- Calendar ใช้สิทธิ์อ่านอย่างเดียวในเวอร์ชันทดลอง จึงไม่สร้าง แก้ไข หรือลบกิจกรรมใน Google Calendar
- API key เก็บในเครื่องของผู้ใช้ ไม่ส่งขึ้น GitHub และไม่ควรเผยแพร่ในภาพหน้าจอ
- ไฟล์ `google-token.json` เป็น token ส่วนตัว ห้ามอัปโหลดขึ้น GitHub
- Google อาจแสดงคำเตือนว่าแอปยังไม่ผ่านการยืนยัน หากเกิดขึ้นให้ตรวจชื่อแอปและรายการสิทธิ์ก่อนดำเนินการต่อ
- บัญชี Google Workspace ของโรงเรียนอาจมีนโยบายบล็อกแอปภายนอก ซึ่งต้องให้ผู้ดูแลระบบอนุญาต
- การใช้ AI อาจมีค่าใช้จ่ายและข้อจำกัดตามผู้ให้บริการ API ผู้ใช้ควรสร้างคีย์ของตนเองและตั้งค่า usage limit

## ติดตั้งสำหรับนักพัฒนา (Dev)

### เตรียมเครื่อง

- Node.js 20 ขึ้นไป
- npm
- Git (ถ้าดึงจาก GitHub)

### ตั้งค่าโปรเจกต์

```powershell
git clone <ลิงก์-repository>
cd study-plannerBeta
npm install
Copy-Item .env.example .env.local
```

เปิด `.env.local` แล้วใส่คีย์ของผู้ให้บริการที่เลือก เช่น:

```dotenv
AI_PROVIDER=qwen
QWEN_API_KEY=วางคีย์ของคุณที่นี่
QWEN_MODEL=qwen3.7-plus
QWEN_BASE_URL=https://dashscope-intl.aliyuncs.com/compatible-mode/v1
GOOGLE_REDIRECT_URI=http://127.0.0.1:4173/oauth/callback
```

ไม่ต้องใส่ Client Secret สำหรับการใช้งานตัวต้นแบบนี้ ตัวแอปมี OAuth Client ID สำหรับ desktop อยู่ในโค้ดแล้ว หากทีมพัฒนาต้องการใช้ OAuth Client ของตนเองจึงค่อยเพิ่ม `GOOGLE_CLIENT_ID` และค่าอื่นในไฟล์ local เท่านั้น

### รันในโหมด Dev

```powershell
npm run dev
```

จากนั้นเปิด `http://127.0.0.1:4173/` หรือใช้:

```powershell
npm run desktop
```

บน Windows สามารถดับเบิลคลิก `run-studyflow-dev.bat` เพื่อเริ่ม server และเปิดหน้าต่าง Dev ได้ ปิดด้วย `stop-studyflow.bat` หากมี server ค้างอยู่

### สร้างตัวติดตั้ง

```powershell
npm run dist
```

ไฟล์ติดตั้งจะถูกสร้างใน:

```text
<โฟลเดอร์โปรเจกต์>\dist\LermLearn Setup 0.1.0.exe
```

ก่อนส่งไฟล์ให้ผู้อื่น ตรวจว่าไม่มี `.env.local`, API key, `google-token.json` หรือ log ที่มีข้อมูลส่วนตัวอยู่ในแพ็กเกจและ Git commit

## ฟังก์ชันหลัก

- ดึงรายวิชา งาน และกำหนดส่งจาก Google Classroom
- แสดงงานที่ยังไม่เสร็จและงานที่ส่งแล้วตามช่วงเวลาที่เหมาะสม
- ปฏิทินการส่งงาน ปฏิทินการติว และปฏิทินการทำงานภายในแอป
- วางแผนงานตามเวลาว่าง เวลาพัก และเวลานอน พร้อมเหตุผลประกอบ
- อ่านไฟล์ PDF, PowerPoint, Word และไฟล์รูปภาพที่ผู้ใช้เลือกภายในขนาดที่ระบบกำหนด
- Summary, Quiz และ Flashcard เป็นคนละโหมดอย่างชัดเจน
- ข้อสอบเป็นตัวเลือกที่กดตอบได้ พร้อมคะแนน เฉลย เหตุผล และแหล่งอ้างอิง
- แฟลชการ์ดมีคำถาม/คำตอบ เหตุผล และอ้างอิงจากข้อความที่อ่านได้
- หากอ่านเอกสารไม่ได้หรือข้อมูลไม่พอ ระบบต้องแจ้งว่าอ่านไม่ได้และไม่แต่งข้อมูลแทน
- ดาวน์โหลดผลลัพธ์เป็น PDF

## โหมดออฟไลน์และการทดสอบ

โหมดออฟไลน์ใช้ข้อมูลตัวอย่างที่อยู่ในโปรแกรมเพื่อทดสอบหน้าจอ Summary, Quiz และ Flashcard โดยไม่ใช้ข้อมูล Classroom และไม่ใช้ API key เหมาะสำหรับการสาธิตเมื่อ OAuth, อินเทอร์เน็ต หรือโควตา API มีปัญหา

## ข้อจำกัดที่ควรแจ้งผู้ทดลอง

- ต้องเชื่อมต่ออินเทอร์เน็ตเมื่ออ่าน Google Classroom, อ่านไฟล์จาก Drive หรือเรียก AI
- ไฟล์ขนาดใหญ่หรือไฟล์ที่เป็นภาพสแกนอาจอ่านข้อความไม่ได้ ระบบจะแจ้งสถานะตามจริง
- `drive.file` เน้นการเข้าถึงไฟล์ที่ผู้ใช้เลือก/อนุญาตผ่านแอป ไม่ใช่การเปิดอ่าน Drive ทั้งหมด
- หากผู้ใช้เปลี่ยนอีเมล ต้องกดออกจากระบบแล้วเชื่อมต่อบัญชีใหม่
- ข้อมูลแผนงานในตัวต้นแบบเก็บในเครื่อง ยังไม่มีระบบ sync ข้ามเครื่อง

## โครงสร้างข้อมูลลับ

- `.env.local` — API key และค่าที่ใช้เฉพาะเครื่อง ห้าม commit
- `google-token.json` — Google OAuth token ส่วนตัว ห้าม commit
- `.env.example` — ไฟล์ตัวอย่างที่ไม่มีค่าลับ ใช้เป็น template ให้ผู้พัฒนา
- `dist/` — ผลลัพธ์ build; ควรเผยแพร่ผ่าน GitHub Release มากกว่าการ commit ไฟล์ build ลง repository

## ใบอนุญาตและการนำเสนอ

ก่อนเผยแพร่จริง ให้ตรวจสิทธิ์การใช้งานโลโก้ ฟอนต์ ไฟล์ตัวอย่าง และข้อมูล Classroom ทุกชุด รวมถึงลบข้อมูลบัญชีทดลองและ token ออกจากเครื่องสาธิตก่อนส่งกรรมการ
