LERMLEARN CONNECTION SETUP

ตั้งค่า AI ก่อนเริ่มใช้งาน

กรอก AI API key ของคุณเพียงอย่างเดียว จากนั้นกดเชื่อมต่อ Google Classroom ในแอปเพื่อเลือกอีเมลและอนุญาตสิทธิ์ที่จำเป็น

สิ่งที่ต้องทำครั้งแรก
  1. เลือกผู้ให้บริการ AI และใส่ API key ของคุณ
  2. กดบันทึกเพื่อเปิด LermLearn
  3. กด “เชื่อมต่อ Google Classroom” แล้วเลือกบัญชี Google ของคุณ
  4. ตรวจสอบรายการสิทธิ์และกดยอมรับ หากบัญชีโรงเรียนถูกนโยบายผู้ดูแลระบบบล็อก อาจเชื่อมต่อไม่ได้
สร้าง Qwen API key (แนะนำ) สร้าง Gemini API key สร้าง DeepSeek API key เปิด Google Cloud APIs
เกี่ยวกับ Google Calendar และความเป็นส่วนตัว
LermLearn สามารถอ่านตารางจาก Google Calendar เพื่อใช้ประกอบการวางแผนการเรียนและการทำงาน โดยคำนึงถึงเวลาว่าง เวลาพัก และเวลานอนของผู้ใช้
ในเวอร์ชันทดลอง ระบบยังไม่แก้ไขข้อมูลใน Google Calendar โดยตรง เพื่อจำกัดสิทธิ์การเข้าถึงข้อมูลส่วนตัวของผู้ใช้และเพิ่มความปลอดภัย ปฏิทินการทำงานของ LermLearn สามารถจัดและแก้ไขแผนได้ภายในแอป
แม้ไม่ต้องเพิ่ม Test users แล้ว Google อาจยังแสดงคำเตือนว่าแอปยังไม่ผ่านการยืนยัน ผู้ใช้ควรตรวจสอบสิทธิ์ก่อนกดยอมรับ และบัญชีโรงเรียนอาจถูกนโยบายของผู้ดูแลระบบบล็อกได้

การเชื่อมต่อ Google ถูกเตรียมไว้ในโปรแกรมแล้ว หลังบันทึกคีย์ให้กดเชื่อมต่อ Google Classroom และเลือกบัญชีของคุณ
